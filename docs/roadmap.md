# Product Roadmap

SpiderSense's long-term product direction includes:

- [ ] Create ZX calculus diagrams.
- [ ] Select and manipulate nodes through a keyboard-driven workflow.
- [ ] Apply rewrites to selected nodes or the whole graph.
- [ ] Apply advanced, efficient rewrites.
- [ ] Recursively group nodes as black-box linear maps within larger diagrams, with groups acting as rewrite boundaries by default.

Each item receives a standalone plan and end-to-end behavioral tests before implementation begins.
